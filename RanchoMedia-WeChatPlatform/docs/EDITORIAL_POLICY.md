# 本轮实际编辑与授权规则

新稿使用中性 RanchoMedia 编辑部口吻，不冒充兰澈本人经历或立场。作者正式样本尚未可靠取得，不能宣称已经学会作者风格。原四篇稿件全部 IN_REVIEW / AUTHOR_APPROVAL_REQUIRED，不能复用其历史检查结果取得发布许可。

研究来源为 Git 官方 commit/push 文档；题材为常青软件知识，不宣称是当日新闻。核心事实C1/C2与来源绑定；Markdown 修改例子明确为假设。网站检查步骤是编辑建议，不声称 Git 官方规定了一套部署验收流程。

真实 Writer 与 Reviewer 使用分开的 codex exec 进程。Reviewer 仅使用提供的原始资料包，不是自主浏览全网的事实裁判。PASS/LOW只表示该稿通过这次自动审查，不代表作者认可、绝对事实保证或其他平台适配稿已通过。

原始 writer answer.json 不修改；网站交付增加可点击S1/S2参考尾注。独立人工/Agent复核仍发现正文重复论证可压缩，因此此稿可用于低风险发布 canary，不能作为作者个人写作风格已验收的证据。

六平台变体由本轮交互式 Codex另行撰写，非第二次无人值守长文生成；变体单独 REVIEW_REQUIRED。视频为原创文字卡片、无音乐无配音，不把脚本称为视频；已实际编码/全片解码。手机播放、裁切、AI内容声明及最终审美仍需人工确认。

自动发送门禁同时要求：账号明确启用、授权人、限定动作和栏目、LOW_RISK_REVIEW_CLEARED、相同文章版本、变体哈希人工确认、媒体和凭据就绪。高风险健康/金融/指控、科研成果宣传、第一人称或未经核实内容不进入本轮 software_explainer 授权范围。

本轮网站单篇发布由用户单独明确授权。授权不延续为日常自动发布、不覆盖其他网站或六平台、不批准微信存量稿。回复评论功能保持关闭；不主动评论第三方作品。
